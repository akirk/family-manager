# Family Manager

A WordPress app powered by [WpApp](https://github.com/akirk/wp-app) for managing a household's children, tasks, appointments, and rewards.

Family Manager stores households, tasks, and rewards as private WordPress content with post meta, and stores family members as taxonomy terms with term meta. Tasks and rewards are assigned to members by tagging them with the member term. The frontend is exposed through the `/family-manager/` WpApp route.
